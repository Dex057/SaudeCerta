# SaúdeCerta — Sistema de Gestão de Clínica

Estudo de caso da disciplina TEADS0347 — Desenvolvimento de Aplicações Multicamadas (IFPA, turma NOITE C795NL, 2026.2).

Sistema web multicamadas para digitalizar o fluxo de atendimento de uma clínica de médio porte: cadastro de pacientes e profissionais, agenda de consultas, prontuário eletrônico, prescrição/exames e controle de acesso com auditoria.

## Estrutura do repositório

- `docs/` — documentação da arquitetura (visão, requisitos, ADRs, diagramas C4, conforme as entregas evoluem).
- `ref/` — material de apoio fornecido pelo professor (guia do estudo de caso).
